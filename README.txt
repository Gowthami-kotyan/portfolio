# Gowthami Portfolio

This is a responsive single-page portfolio inspired by the screenshots you provided.

## Before publishing

1. Replace `profile.jpg` with your own photo.
2. Replace `YOUR_EMAIL@gmail.com` in `index.html` with your professional email.
3. Replace `YOUR_GITHUB` with your GitHub username.
4. Replace `YOUR_LINKEDIN` with your LinkedIn username.
5. Put your resume PDF in this folder and name it `resume.pdf`.
6. If any project/skill differs from your actual work, edit it in `index.html`.

## Publish on Netlify

Drag the whole `gowthami-portfolio` folder into Netlify's deploy area, or upload the ZIP after extracting it.
